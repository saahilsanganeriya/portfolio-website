Project page: [entity resolution and anonymization](/projects/entity-resolution-and-anonymization)

  concurrency controller.

## Projects

**swe-sim** · graded coding-agent tasks from real GitHub issues · Sep 2026

Project page: [swe-sim](/projects/swe-sim) · [code](https://github.com/saahilsanganeriya/swe-sim)

- Built a pipeline that turns underspecified GitHub issues into coding-agent tasks, with an LLM stakeholder
  the agent can question.
- Graded each patch offline, dropping edits to protected tests and paying out only when four records of the
  hidden-test run agree.
- Ran it on Temporal, Modal and Cloud Run. The first hosted task (29 trials, $3.01) exposed a task defect
  that a new gate now rejects.
